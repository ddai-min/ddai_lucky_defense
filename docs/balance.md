# 난이도와 밸런스

이 게임의 난이도가 어떻게 정해졌는지, 그리고 왜 그렇게 정했는지에 대한 기록입니다.
플레이 방법만 알고 싶다면 [README](../README.md) 로 돌아가세요.

수치는 전부 [`lib/game/data/balance.dart`](../lib/game/data/balance.dart) 한 곳에 모여 있습니다.

```dart
static const List<double> damage = [10, 34, 116, 400, 1400, 5200, 21000]; // 등급별 공격력
static const double baseHp = 110;                                         // 1웨이브 체력(전 모드 공통)
static double enemyHp(int wave, GameMode mode) { ... }                    // 몬스터 체력 곡선
static int summonCost(int unitCount) => 20 + 39 * unitCount;              // 소환 비용(최대 800G)
static const int startGold = 600;                                         // 시작 골드
static List<double> summonWeights(int luck) { ... }                       // 등급별 소환 확률
```

유닛을 추가하려면 `unit_catalog.dart` 의 `kUnitCatalog` 에 `UnitSpec` 한 줄만 넣으면
도감·소환·합성에 자동으로 반영됩니다.

## 난이도 시뮬레이터

수치를 바꿨을 때 실제로 몇 웨이브까지 버티는지 감이 아니라 숫자로 봅니다.
공식은 `Balance` 를 그대로 가져다 쓰므로 게임과 어긋나지 않습니다.

```sh
dart run tool/balance_sim.dart           # 현재 밸런스 리포트
dart run tool/balance_sim.dart --curve   # 웨이브별 여유 (--easy / --normal / --hard 로 모드 지정)
dart run tool/balance_sim.dart --levers  # 조정 레버별 효과 비교
dart run tool/balance_sim.dart --luck    # 운이 당락을 가르는지 측정
dart run tool/balance_sim.dart --gems    # 다이아를 어디에 쓰는 게 이득인지
```

**쉬움·보통·무한의 난이도는 몬스터 체력 곡선 하나로만 갈립니다.**
어려움만 규칙이 하나 더 다릅니다(아래 «어려움은 왜 규칙이 다른가»).

모든 곡선은 `baseHp`(1웨이브 체력)에서 출발합니다. 이 한 값이 전 모드의 체력을
곱으로 밀어 올리는 손잡이입니다.

끝나는 웨이브는 모드마다 다릅니다 — 쉬움·보통은 100, **어려움은 150**, 무한은 없습니다
([`Balance.clearWave`](../lib/game/data/balance.dart)).

| 모드 | 곡선 | 30웨 | 60웨 | 100웨 | 결승선 | 도달률 |
| --- | --- | --- | --- | --- | --- | --- |
| 쉬움 | `110 × 1.053^(w-1)` | 492 | 2,316 | 18,273 | 100웨 | 99% |
| 보통 | 꺾인 곡선(아래) | 3,651 | 44,526 | 384,910 | 100웨 | **11%** |
| 어려움 | 꺾인 곡선 + 눕는 뒷구간 + 초월 도박 | 3,147 | 34,503 | 272,156 | 150웨 349,237 | **3%** |
| 무한 | `110 × 1.125^(w-1)` | 3,348 | 114,655 | 12,749,478 | — | — |

보통은 단순히 배율을 올린 게 아니라 **곡선 모양이 다릅니다.** 플레이어 전투력은
«초월» 에서 멈추므로 후반에는 더 늘지 않습니다. 체력만 끝까지 같은 비율로 올리면
중반 50 웨이브가 손 놓아도 되는 구간이 되고 마지막 몇 웨이브만 난이도가 됩니다 —
쉬움 곡선이 딱 그렇습니다(중반 여유가 10배 안팎까지 벌어집니다). 그래서 보통은
증가율을 웨이브마다 조금씩 꺾어(`1.154`에서 시작해 매 웨이브 `0.9875`배) 여유가
처음부터 끝까지 비슷하게 유지되도록 했습니다.

증가율은 아주 예민한 값입니다. 소환 비용을 올리기 전 측정에서는 0.002만 더 올려도
숙련자 도달률이 5분의 1 이하로 주저앉았습니다(`1.186`→`1.188` 에서 85%→18%) —
후반에는 플레이어가 한계에 닿아 더 셀 수 없기 때문에 이 언저리가 난이도가 급격히
꺾이는 지점입니다.

**도달률은 실력 분포 전체에 걸쳐 잽니다.** 커버리지를 한 값으로 고정해 재면
도달률이 100% 아니면 0%로 튑니다 — 후반에는 누구나 «초월» 에서 멈춰 전투력이
같아지기 때문에, 그 한 사람이 깨느냐 마느냐로 결과가 갈리는 탓입니다.

### 어려움의 마지막 50웨이브는 왜 눕는가

결승선이 150이라고 곡선을 그냥 늘리면 안 됩니다. 100 → 150 구간에서 꺾인 곡선은 아직
**체력이 7배** 오르는데, 플레이어는 «초월» 에서 멈춰 강화분만 늡니다. 실제로 그대로
늘려 봤더니 도달률이 3%에서 **0%** 가 됐습니다 — 아무도 못 깨는 모드가 됩니다.

그래서 어려움 곡선은 두 구간입니다.

- **1~100웨이브** — 꺾인 곡선(`1.147`에서 시작해 매 웨이브 `0.9875`배).
- **100~150웨이브** — 웨이브당 `1.005` 배. 50웨이브 동안 1.28배만 오릅니다.

결승선을 150으로 늘린 뒤에도 도달률은 3% 대를 유지합니다.

## 지옥은 왜 «어려움 곱하기» 인가

지옥을 만들 때 먼저 해 본 것은 체력 곡선을 통째로 올리는 것이었다. **증가율을
0.005 올리자 도달률이 3.4% 에서 0% 가 됐다.** 시뮬레이터로 한 판을 들여다보니
이유가 분명했다 — 판이 **11웨이브에서 초월 0기로** 죽는다. 초월을 보기도 전에
끝나므로 «초월이 더 필요한 모드» 가 아니라 «아무도 못 깨는 모드» 가 된다.

초월 피해 배수를 4배에서 12배까지 올려 봐도 도달률이 소수점까지 똑같았다. 같은
이유다. 초월이 없는 판에는 초월 보너스가 아무 일도 하지 않는다.

그래서 초반은 어려움 그대로 두고 **50웨이브부터** 조이기로 했다. 여기서 한 번 더
틀렸다. «50까지 어려움 곡선, 그 뒤는 고정 증가율» 로 짰더니 **51웨이브에서 지옥이
어려움보다 약했다.** 어려움의 꺾인 곡선은 그 지점에서 웨이브당 7.6% 씩 오르는데,
고정 5.5% 가 그보다 완만했기 때문이다.

그래서 곡선을 새로 그리는 대신 **어려움에 곱했다.**

    지옥 체력 = 어려움 체력 × 1.020^(웨이브 - 50)

이러면 어떤 웨이브에서도 지옥이 어려움보다 약할 수 없다. 테스트가 400웨이브까지
이 부등식을 지킨다.

| 곱하는 값 | 100웨 체력 | 150웨 체력 | 도달률 | 깬 판 초월 | 깬 판 수 |
| --- | --- | --- | --- | --- | --- |
| 1.014 | 545,400 | 1,402,542 | 1.83% | 5기 (3~8) | 44/2400 |
| 1.018 | 664,058 | 2,079,209 | 0.47% | 6기 (4~8) | 15/3200 |
| **1.020 (지옥)** | **732,531** | **2,530,099** | **0.19%** | **6기 (6~8)** | **6/3200** |
| 1.022 | 807,908 | 3,077,585 | 0.03% | 6기 (6~6) | 1/3200 |
| 1.025 | 935,429 | 4,125,788 | **0.00%** | — | 0/3200 |

1.020 을 골랐다. 500판에 한 번쯤 깨지고, 깨는 판은 초월을 6기 이상 세운 판뿐이다.
도박이 15% 라 8기는 사실상 뽑기 운의 천장이다. 1.022 는 3,200판에 한 판이라
«깨진다» 고 말할 표본이 못 된다.

**0.005 만 더 올리면 0% 다.** 이 근처에서는 체력을 올리는 것이 도달률과 1:1 이
아니라 절벽으로 맞바꿔진다 — 플레이어 전투력이 초월에서 멈추기 때문이다. 소환
비용·피해표·슬롯 수를 건드리면 이 값도 같이 다시 재야 한다.

### 라이프 1

지옥은 시작 라이프가 1이고(`Balance.hellLives`) 다이아로 살 수도 없다
(`GameMode.canBuyLife`). 한 마리만 성에 닿아도 그대로 끝난다.

위 표는 **라이프 20 시절에 잰 것이라 지금 도달률은 이보다 낮다.** 같은 곡선에
라이프만 1로 주고 3,200판을 돌려 보면 깬 판이 나오지 않는다.

    dart run tool/balance_sim.dart --top

«초월 몇 기면 깨지는가» 는 위 명령으로 언제든 다시 잴 수 있다. 도달률만 보면
모드가 어려운 것은 알아도 무엇이 모자라서 못 깨는지는 알 수 없다. 표본보다 낮은
도달률은 0% 로 찍히므로, 리포트가 깬 판 수를 함께 보여 준다.

## 어려움은 왜 규칙이 다른가

이름은 «운빨» 디펜스인데, **운은 사실상 아무것도 결정하지 않습니다.** 실력을
고정하고 400판을 돌리면 100웨이브에서 판마다 벌어지는 전투력 차이가 1.10배뿐이고,
끝난 웨이브도 전부 99~100입니다. 한 판에 유닛을 수백 번 뽑으니 뽑기 운은 평균으로
수렴하고, 후반에는 누구나 21칸을 초월로 채워 같은 자리에서 멈추기 때문입니다.

그래서 **체력만 올리면 «운 좋으면 깬다» 가 아니라 «아무도 못 깬다» 가 됩니다.**
실력이 조금만 달라져도 도달률이 통째로 뒤집힙니다(보통: 0.70 에서 10%, 0.80 에서 90%).

어려움은 최고 등급을 도박으로 만들어 그 편차를 벌립니다. `--luck` 이 재는 값입니다.

```
운빨 폭 — 같은 실력, 판마다 벌어지는 전투력 (p90 ÷ p10)
모드     20웨    40웨    60웨    80웨    100웨
보통     4.13    2.23    1.59    1.50    1.30
어려움   4.13    2.23    1.59    5.63    7.90

실력별 도달률 — 평평할수록 운이 가른다 (모드마다 끝나는 웨이브가 다르다)
모드     0.55    0.65    0.70    0.75    0.80
보통     0%      3%       8%     20%     28%
어려움   3%      4%       8%      8%     11%
```

어려움은 후반 운빨 폭이 **7.9배** 까지 벌어집니다. 실력을 통째로 바꿔도 3~11% 에
머무니, **당락을 가르는 게 실력이 아니라 뽑기입니다.**

소환 비용을 올린 뒤로는 전 모드의 운빨 폭이 커졌습니다(20웨 2.47 → 4.13). 뽑는
횟수가 줄면 평균으로 수렴할 기회도 줄기 때문입니다 — 이 게임 이름에 맞는 방향입니다.

초월을 4배로 키운 건 연출이 아니라 **도박이 성립하기 위한 조건**입니다. 신화 3개를
그대로 두면 21,528 DPS 인데 15% 에 걸어 실패하면 1개만 남으므로, 초월이 원래 수치면
기댓값이 10,982 로 반토막입니다 — 즉 **합성하지 않는 쪽이 최적**이 되어 규칙이 통째로
함정이 됩니다. 4배로 키우면 기댓값이 25,630(1.19배)이 되어 거는 쪽이 이득이 됩니다.

이 보정을 모든 모드에 주면 쉬움·보통이 복구 불가능해집니다. 전투력 곡선이 계단이
되어 곡선이 그 계단 위나 아래에만 놓이기 때문입니다 — 쉬움은 증가율 1.12 에서 100%,
1.14 에서 0% 로 튀고 중간이 없습니다. 그래서 도박도 보정도 **어려움 전용**이고,
쉬움·보통·무한 수치는 한 줄도 건드리지 않았습니다.

어려움에서 못 깨는 판은 중반에 멈춥니다(라이트 기준 45웨이브). 보통과 달리 «결승선 앞»
이 아닙니다. 벽을 뒤로 밀 수는 있지만(`taper` 를 1.0 쪽으로) 그러면 30웨이브 여유가
3.1배에서 11.6배로 벌어져 **보통보다 쉬운 «어려움»** 이 됩니다. 60웨이브 운빨 폭이
8배라 한 곡선으로 «운 나쁜 판» 과 «운 좋은 판» 을 동시에 팽팽하게 만들 수는 없습니다.

### 초월 셋은 DPS 가 같다

초월 셋(창세의신 🌟 광역 · 종말의신 ☄️ 처형 · 심판의신 ⚖️ 단일)은 **DPS 가 서로 같습니다.**
갈리는 건 공격 방식과 사거리뿐이라 합성에서 무엇이 나오든 기본 전투력은 그대로입니다
(도박의 기댓값 계산이 등급 기본치로 서 있기 때문입니다). 테스트가 이 조건을 지킵니다.
다만 종말의신의 즉사는 DPS 밖의 덤이라 모델에 잡히지 않습니다 — 많이 뽑으면 실제로는
그만큼 더 셉니다. 그것도 운입니다.

## 고급소환은 왜 «콕 집어» 주는가

다이아 수입은 한 판에 95개(보스 10번)인데 **행운을 끝까지 올리는 데만 225개**가 듭니다.
한 판에 행운을 채울 수 없으니, 다이아는 언제나 행운에 넣는 게 이득입니다 — 12다이아짜리
고급소환은 행운 3~4레벨을 포기하는 값이었습니다. 게다가 보장하는 건 **등급뿐이고 종류는
복불복**이라, 유니크 4종 중 필요한 게 나올 확률은 1/4 입니다. 비싼 값을 치르고도 쓸모없는
유닛이 나오는 구조였습니다.

`--gems` 가 정책을 겨뤄 줍니다.

```
다이아 쓰는 법            무한    보통    어려움
전부 행운                 39웨    28%     11%
전부 고급소환             41웨     1%      5%
행운 6렙까지 → 고급소환   39웨    31%     21%
행운 10렙까지 → 고급소환  39웨    28%     11%
행운 14렙까지 → 고급소환  39웨    28%     11%
```

**소환 비용을 800G 로 올린 뒤 결론이 뒤집혔습니다.** 예전에는 «언제나 행운» 이 최적이고
고급소환은 눌러 볼 이유가 없는 버튼이었지만, 지금은 **행운을 6레벨까지만 올리고 남는
다이아를 전부 고급소환에 쓰는 쪽이 가장 좋습니다**(어려움 11% → 21%). 소환 한 번이
800G 인 세상에서는 «공짜로 받는 유닛» 의 값어치가 그만큼 커지기 때문입니다.

- 종류까지 보장합니다 — 2개 모아 둔 유닛이 있으면 **그걸** 줍니다. 복불복이 사라집니다.
- 무엇이 나올지 누르기 전에 보여 줍니다(자동 판매 예고와 같은 방식).
- 8다이아로 내렸습니다 — 40웨이브 이후 **보스 하나가 고급소환 한 번**이 되는 리듬입니다.

신화 이상은 겨냥하지 않습니다. 합성 전용 등급을 돈 주고 사면 등급 규칙이 깨집니다.

근본 원인(행운이 다이아를 독식하는 구조)은 그대로입니다. 이걸 바꾸려면 행운 비용 곡선을
손봐야 하는데, 그건 모든 모드의 밸런스를 다시 맞추는 일이라 따로 두었습니다.

## 모델의 한계

**가장 불확실한 값은 «커버리지»** 입니다. 사거리 밖이거나 재장전 중이라
명목 DPS 가 전부 몬스터에게 닿지는 않는데, 이걸 숙련자 0.80 · 라이트 0.55 로 가정합니다.
유닛 배치 전략과 둔화·중독 시너지는 모델에 없습니다. **절대 웨이브 수는 어림값이고,
레버 사이의 상대 비교가 믿을 만한 부분**입니다.

~~모델은 등급별 기본치만 쓰고 유닛마다 붙은 배율은 무시합니다.~~ **고쳤습니다**
(`kUnitMultipliers`). 이 근사 때문에 초월 한 기를 신화의 18.1배로 보고 있었는데,
실제 도감 배율을 넣으면 25.8배입니다. **초월이 필요한 기수가 부풀려져 있었고**,
고친 뒤 도달률이 어려움 3% → 10%, 보통 11% → 32% 로 올랐습니다. 이전 문서에 적힌
도달률 수치는 그만큼 비관적이었다고 보시면 됩니다.

복사해 온 배율이 도감과 어긋나지 않도록 테스트가 지킵니다
(«시뮬레이터가 복사해 쓰는 상수가 실제 게임과 맞는다»).

## 직관과 어긋난 것들

시뮬레이터가 알아낸 것 중 «그럴 것 같았는데 아니었던» 것들입니다.

| 조정 | 생존 웨이브 변화 |
| --- | --- |
| 슬롯 18 → 24 | **±0** — 슬롯이 늘면 소환 비용도 오르고, 어차피 합성으로 압축된다 |
| 강화 비용 대폭 인하 | **±0** — 효과는 선형, 체력은 지수라 못 따라간다 |
| 보스 체력 ×32 → ×20 | **±0** — 보스는 사망 원인이 아니다(창이 1.65배 길어 오히려 여유) |
| 라이프 20 → 30 | +2 — 무너지기 시작하면 순식간이라 버퍼가 무의미하다 |
| 몬스터 체력 증가율 | **압도적** — 사실상 이것 하나가 난이도를 결정한다 |
| 골드 수입 ×0.5 | 운빨 폭 **±0** — 뽑는 횟수를 줄여도 평균으로 수렴하는 건 똑같다 |
| 상위 합성을 도박으로 | 운빨 폭 1.10배 → **2.38배** — 편차를 벌리는 건 이것뿐이다 |
| 소환 비용 `20+6n`→`28+10n` | 체력은 그대로인데 보통 도달률 26% → **0%** — 체력 못지않게 센 레버다 |
| 소환 비용 최대 184G → 800G | 전투력이 **60웨에서 0.20배** — 네 모드 곡선을 전부 다시 맞춰야 했다 |
